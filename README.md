# Key-sound-control 🎧🔊

Aplicación en segundo plano para Windows para el enrutamiento y control individual de salidas de audio por aplicación y ventana.

## Visión general
Permite redirigir el audio de ventanas o aplicaciones específicas (por ejemplo, una ventana de Google Chrome con música o video) hacia un dispositivo de salida de audio seleccionado (altavoces, auriculares, monitor, etc.), manteniendo el resto del sistema en el dispositivo predeterminado.
